# Lab 6.2: Solution: Write a Transfer Note

Individual solution; the example below shows the expected depth.

## Tasks

### 1. to 4. Example note

| Field                      | Entry                                                                  |
| -------------------------- | ---------------------------------------------------------------------- |
| Use case                   | internal IT helpdesk assistant that answers repeated password and VPN questions |
| Closest integration option | publishing to Microsoft Teams                                          |
| Main constraint behind it  | channel: employees already work in Teams and will not open a new tool  |
| First step                 | grounded prototype on the existing helpdesk article set, tested with ten real questions |
| One risk to resolve first  | owner of the helpdesk articles after go-live                           |

## Criteria for a sound note

| Criterion                              | Sound                                              | Not sound                          |
| -------------------------------------- | -------------------------------------------------- | ---------------------------------- |
| option linked to a constraint          | "channel: users are in Teams"                      | "Teams is modern"                  |
| first step                             | startable within a week, observable result         | "evaluate the platform"            |
| risk                                   | quota, access, or document owner                   | "it might not work"                |

## Typical mismatches and corrections

| Mismatch                                      | Correction                                                 |
| --------------------------------------------- | ---------------------------------------------------------- |
| Agent Framework chosen without a pattern gap | stay on Foundry Agent Service until a pattern cannot be expressed |
| A2A chosen for a single-project agent        | A2A is needed once agents span teams or organisations      |
| no human-approval point for money or access  | add the approval boundary before the first pilot           |

## Checkpoint

- Five fields filled, option tied to a constraint, first step concrete, risk named
